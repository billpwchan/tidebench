# 专业工作台交付清单 · v0.17.0

本次以研究候选决策、账户监控、订单执行为核心任务。保留真实金融口径、来源和权限边界；完成下列验收后发布，不以配色升级或测试数量代表机构认证。主工作目录中的其他未提交研究工作不进入本次发布。

## 设计依据

- [TradingView 多图工作区](https://www.tradingview.com/support/solutions/43000629990-leveraging-multi-chart-layouts-in-your-analysis/)：工作区需要可恢复的布局和明确的对象联动。
- [QuantConnect 回测分析](https://www.quantconnect.com/docs/v2/research-environment/meta-analysis/backtest-analysis)：结果应能追踪到交易与原始数据，比较不能只并排展示收益。
- [NN/g 渐进呈现](https://www.nngroup.com/articles/progressive-disclosure/)：默认呈现频繁任务，保留可发现的完整依据及高级选项。

采用冷灰/纸白/青色系统，强化文字和数值层级。交易风险与盈亏的语义颜色独立于操作强调色。紧凑布局仍保留触控与键盘目标；手机按任务重新排序。

## 自我挑战与验收口径

1. 未加载或未验证的数据不能被新决策摘要包装为肯定结论。前端说明不替代后端准入。
2. 保存布局不能保存密码、token、交易提交或过时的权限；恢复工作台只导航并重新请求当前证据。
3. 紧凑表格不能让用户误读零值、数量单位、资金费是否待结算或准确盈亏；固定关键列仍需实际几何验收。
4. 图表/表格/票据联动必须明确当前对象和来源；禁止将回测收益当成账户表现。
5. 自动化任务验收衡量界面行为、操作步骤和可恢复性；不冒充真实交易员可用性测试。
