# 专业工作台任务与交互审查 · v0.17.0

本轮针对研究决策、账户监控和订单执行完成任务结构与交互升级。以能否找到当前对象、解释证据限制并完成下一步为验收标准；不以界面风格、自动化计数或模拟某家机构的视角代替实际交易员可用性测试。

## 调研与设计判断

- [TradingView 工作区与对象同步](https://www.tradingview.com/support/solutions/43000629990-leveraging-multi-chart-layouts-in-your-analysis/)将布局和品种联动明确区分。这里采用可恢复布局与清晰对象上下文；没有实现或宣称其多图产品功能。
- [QuantConnect 回测分析](https://www.quantconnect.com/docs/v2/research-environment/meta-analysis/backtest-analysis)提供资金曲线、交易与底层记录分析路径。这里把已核验的结果、成本和时段作为比较依据，保留原始记录入口。
- [NN/g 渐进呈现](https://www.nngroup.com/articles/progressive-disclosure/)支持优先呈现常用任务，再访问高级细节。本轮用原生可键盘展开区保留完整身份和金融依据。

真实部署的上一版既有 OKX 研究在 390×844 首屏仅露出约 82px 主图，虽然较短合成用例通过 120px 门槛。研究页面把草稿、目录、记录和分析同时暴露；执行页叫 Portfolio，打开票据后可能滚离账户摘要。仅调整配色不足以解决这些问题。

独立审查要求证据说明绑定当前候选；计算完成、正收益、Sharpe 和样本量不能自动代表有效策略或模拟准入。账户警告不能被偏好或快捷动作隐藏，未知风险与资金值不能当成零。

## 已实施的任务路径

1. 侧栏的三个核心入口为 Overview、Research、Execution；策略、数据、运维和设置仍有可发现入口，既有深链接继续使用来源和对象身份。
2. 单策略研究分为 Result analysis、Next trial draft、Study ledger 三个任务。查看历史不覆盖草稿；配置复制仍是显式操作。完整运行、版本、holdout、数据集与成本进入原生展开区。六个分析分类和原始执行记录保留。
3. 已核验证据摘要列出 UTC 时段、完整日与完成交易数、费用和滑点；样本不足及开发/训练/样本外/成本敏感性范围有明确说明，下一步通向相关分析或独立草稿。前端摘要不替代服务器模拟准入审查。
4. 试验比较展示配置口径差异、各自身份和收益范围；不同市场、时段、资本、杠杆、成本和评估方式不会被包装成统一排名。
5. 账户研究记录显示可识别策略名称和运行身份，可直接打开具体结果。空账户减少无用占位；账户/敞口仍使用同一捕获快照，经济异常与服务健康分别呈现。
6. Execution 的标题与入口统一。桌面打开票据保留账簿位置；票据就近显示可用现金、权益、保证金、捕获时间、风险开关和资金费异常。市场搜索、收藏与最近市场只准备草稿，保留既有报价时效、数量单位、风险预览、确认与后端权限检查。
7. 布局支持信息密度、监控预设、票据宽度及已命名工作台。表格保存合法列集合/顺序、筛选和数值排序，关键身份、金融值、风险与操作列不可通过偏好关闭；手机主摘要按明确优先级呈现，其余字段仍在行详情可检查。偏好按用户、来源、页面及字段版本隔离；不保存订单参数、预览、确认、批准、命令键或选中交易。
8. Command/Ctrl Shift K 提供任务搜索；Command/Ctrl K 保留市场搜索。新命令忽略输入框、中文组合输入、对话框、滑块与图表焦点；命令只导航或打开草稿，不提交交易或批准发布。对话框约束焦点并使背景不可交互。
9. 手机采用紧凑任务名称、三个核心研究指标及可展开完整口径。存储损坏或不可用时明确反馈并降级；界面语言同样能在存储不可用时继续使用。

## 自我挑战后的修正

初次代码审查发现保存账本、发布记录、归因等只读视图被静默改为持仓视图；修正为保留合法只读视图及精确记录身份，仅移除订单草稿和保护指令。审查还发现新票据只重复 funding_pending 告警，遗漏 funding_schedule_unavailable 等异常；票据与页面监控条改为共用经济状态映射。

展示偏好使用字段白名单并限制大小，修正同一事件中多次写入和来源切换时的竞争。表格不保存展开金融记录或分页中的选中对象；恢复视图会重新请求当前数据和权限。

首轮定向浏览器运行通过 47 项、跳过 5 个明确桌面专用手机用例、失败 12 项。实际发现短屏桌面主图仅有 170.5px、现货不适用的强平列挤压盈亏、阻止整个 Storage API 时读取服务 token 导致 Cookie 登录路径不可用。修复短屏间距、仅在存在永续持仓时保护/呈现强平字段、受阻 token 读取安全返回空值以继续服务器 Cookie 认证；服务 token 写入的原有失败反馈保留。其余失败来自重复名称定位器与替换模拟场景后未刷新初始查询；用明确列表/按钮范围及新场景初始请求修正，不放宽实际几何门槛。原始失败截图、日志与 trace 保存在私有交付目录。

完整首轮浏览器回归通过 307 项、跳过 8 个明确桌面专用手机用例、失败 9 项（12.3 分钟）。其中复现手机持仓完整首行底部为 750px、超过 664px 首屏，以及 1110px 研究草稿标题/按钮横向溢出。修复手机工具条为搜索、排序和 44px 列设置三列；关键字段不能关闭，但不自动增加手机摘要字段，市场价值保留在行详情；研究标题和动作自然换行。其他失败是旧模糊数量定位器匹配到新增列控件，改为精确订单票据 spinbutton；保留订单提交、延迟回执、风险开关和持仓断言。未降低几何门槛或删减流程断言。

固定提交 `964b9abc` 的完整回归通过 316 项、8 个明确桌面专用手机用例跳过（12.7 分钟）。随后真实历史研究的私有副本使用路径验收发现手机从所选结果进入草稿时，两项配置动作使整页宽度变为 452px；此前合成用例没有断言这个状态。修复配置动作区为双列自然换行，并在既有完整任务路径中补充中英文横向几何和 44px 操作目标断言。分析首屏实测保留桌面约 245px、手机约 196px 主图，完整运行身份仍可展开查看。补充测试的首轮两个用例在中英文几何断言均通过后，恢复英文时因仍按英文名称定位已翻译的语言控件超时；定位器修正为中英文可访问名称，保留原断言。新版提交再次进行完整回归与精确源码 CI；旧提交 CI 因源码已被替代主动取消，不计为通过。

## 边界

本轮仍为 OKX 公共数据、回测和本地模拟执行，不新增实盘交易。浏览器自动化和内部独立代码/截图审查不能证明真实买方团队长期使用满意度、策略盈利、全站 WCAG 认证或高可用 SLA。生产重建会有容器切换窗口；不承诺零停机。
