# v0.8.0 策略实质审计

## 发现与处理

此前配方以单指标为主，不能仅凭止损与版本化称为专业策略。本轮审查经济假设、因果边界、成本、失效状态与证据迁移，交付两个共享信号模型和资金费率配对成本门槛，而非只增加策略名称。

- 多周期动量：一／二／四周标准化收益必须一致，否则清仓；不把分数解释成概率或显著性，不把信号标准化称为目标波动率仓位。
- 回归：当前收盘不进入参考均值；方向效率或波动过滤触发时清仓。价格 Z 分数不冒充协整价差。
- 资金费率：历史实际结算严格滞后于决策 K 线起点；增加样本数、时效和双腿四次开平仓成本。预测按结算次数表达，不固定假设每日三次，也不承诺持有至回本。
- 同一数值实现用于历史、持久化前向模拟与重启检查点；新模型缺失价格状态时拒绝恢复，不能悄悄重置为零。
- 新资金费率参数绑定不可变组合与冻结评估；旧定义仍保留明确的仅费率语义，修改需新版本。

## 必须保留的反证

[真实 OKX 108 案例](v0.8.0-strategy-battery.json)覆盖三币、一年 4 小时数据、两个独立空仓时段、两档成本、相邻参数及过滤消融。默认动量仅 4/12 情景为正，回归为 6/12；过滤器没有一致改善消融版本。相同市场／时段／成本的案例相关，不能当作独立检验。没有根据结果重调主参数，也没有删除亏损案例。

买入持有对照配置上限相同，但风险预算／止损降低策略实际敞口，故不是风险匹配 alpha 比较。当前规则与当前选定品种存在历史可交易性／幸存者偏差限制；此报告仅检验现货策略，不验证资金费率配对盈利或永续做空收益。完整往返交易样本偏少时，收益与 Sharpe 仍不足以证明稳定优势。

运行器最初因清单字段与 Decimal 序列化出错，未完成案例集；修复后完成并保存原始结果，再从本地捕获重放全部 108 个输入／结果哈希。失败不被包装为验收通过。

## 针对性验收

独立公式核对（收益滞后、总体方差、排除当前价格的均值）、未来价格扰动、零方差／波动冲击、方向约束、下一开盘成交、捕获重放、真实本地账本前向重启；正费率仍无法覆盖四次费用、当前结算排除、数据不足／陈旧／负费率分离；历史与前向配对均保留拒绝开仓证据。桌面／手机检验双语研究库、可执行配方保存与页面宽度。

完整方法、原始来源、复现命令与数值结果见 [策略研究说明](../strategy-research.md)。完整 CI 与实际测试数量以该发布提交的验证记录为准。实现通过不等于投资优势通过；策略库必须允许得出“该假设不值得部署”的结论。
